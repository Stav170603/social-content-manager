# Smart Social Content Manager

A full stack platform for managing social media content, clients and approval 
workflows.

## Project Context

Collaborative academic project developed as part of my B.Sc. studies.
I worked as a Full Stack Developer and contributed to both frontend and backend development.

## Overview

The system was built to support a complete content management process between administrators and clients. It allows content creation, review, approval, rejection, resubmission, publishing and analytics management from one platform.

## Tech Stack

Frontend: React, Vite  
Backend: Java, Spring Boot  
Database: MySQL  
APIs and Services: REST APIs, Cloudinary, Meta Instagram API  
Tools: Git, GitHub, Maven, VS Code, IntelliJ IDEA, MySQL Workbench

## Main Features

• Admin and client workflows  
• Role based permissions  
• Content approval and rejection process  
• Rejection reason and resubmission flow  
• Image upload and media management with Cloudinary  
• Instagram publishing integration  
• Dashboard and analytics screens  
• Account and media insights  
• Input validation and error handling  
• Secure password storage with BCrypt  
• Integration testing

## Architecture

The project follows a client server architecture.

The frontend communicates with the backend through REST APIs.  
The backend handles business logic, authentication, validation and database operations.  
MySQL is used for persistent data storage.

## What I Worked On

I worked on the project as a Full Stack Developer and implemented features across the frontend, backend and database layers.

My work included:

• Building React interfaces and workflows  
• Connecting frontend screens to Spring Boot REST APIs  
• Implementing approval, rejection and resubmission flows

## Project Goal

The goal of the project was to build an end to end content management system that demonstrates full stack development, API integrations and real product workflows.
